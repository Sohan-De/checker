# Site Launch QA Checker 🚀

A high-performance codebase for digital agencies to automate website audits during the launch phase. 

## 🏗️ Project Structure

This project follows a clean, decoupled architecture:

- **`backend/`**: Python 3.x FastAPI server and core scanning logic.
  - `app/`: Core logic (Crawler, Scanner, Checks).
  - `config/`: JSON-based scanning rules.
  - `input/`: Target URLs for batch processing.
  - `api.py`: REST API entry point.
  - `cli.py`: CommandLine Interface for automated audits.
- **`site-launch-ui/`**: Modern React Dashboard (TypeScript + Vite + Framer Motion).
- **`reports/`**: CSV audit logs generated by the system.

## 🚀 Getting Started

### 1. Backend Setup
Navigate to the backend directory and install dependencies:
```powershell
cd backend
pip install -r requirements.txt
python api.py
```
*The API will be live at `http://localhost:8000`.*

### 2. Frontend Dashboard
In a new terminal, launch the React development server:
```powershell
cd site-launch-ui
npm install  # (First time only)
npm run dev
```
*Access the dashboard at `http://localhost:5173`.*

---

## 🛠️ Advanced Usage

### Terminal Audits (CLI)
To run a batch scan of multiple sites without the UI:
```powershell
python -m backend.cli
```
*Configure target sites in `backend/input/sites.txt`.*

### Custom Rules
Modify `backend/config/rules.json` to add new detection patterns:
```json
{
  "name": "Custom SEO Check",
  "type": "fail_if_found",
  "pattern": "custom-pattern"
}
```

## ⚡ Performance
Designed using `asyncio` and `aiohttp`, the tool can auditor 50+ pages in under 30 seconds, depending on network latency.
